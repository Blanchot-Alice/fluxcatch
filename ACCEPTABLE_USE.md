# Acceptable Use

FluxCatch is intended for media that the user created, owns, is licensed to download, or has explicit permission to save.

Users must respect copyright, contractual restrictions, website terms, privacy rights, and applicable law. FluxCatch must not be used to bypass DRM, paywalls, login restrictions, or technical access controls, or to obtain or redistribute media without authorization.

FluxCatch 0.2.5 is a development/GitHub candidate, not the Chrome Web Store artifact. A future Store build must physically exclude capabilities that are outside its reviewed scope and enforce its platform restrictions without runtime overrides.
